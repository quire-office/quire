## 2. 診斷過程與證據

### 2.1 排除 (a)：SVG 輸出乾淨

`cargo run -q -p quire-cli -- render corpus/poi/test-data_document_Bug51170.docx --out /tmp/k26-a`
→ 7 頁 SVG。逐檔掃描結果：

| 檢查項 | 結果 |
|---|---|
| 元素種類 | 僅 `<svg>`×7、`<rect>`×7、`<text>`×224、`<image>`×6，無 line/path/polygon |
| rect | 每頁僅 1 個：`<rect width="100%" height="100%" fill="#ffffff"/>` 白背景，無非白 rect |
| `stroke=` | 全部 7 檔 **0 命中**（無任何描邊，無从誤繪頁框） |
| 非 text 元素的黑色 fill | 0 命中（black fill 只出現在文字字色，屬正常內容） |
| 越界圖元（x<0 或 x≥590） | 0 命中 |
| viewBox | `0 0 595 842`（A4 pt），無外溢繪製 |

→ **SVG 內不存在貼邊黑色 rect/line，(a) 排除；亦無頁框 border 誤繪，(c) 排除。**

### 2.2 定位 (b)：合成器畫布幾何

像素掃描 `cmp-latest.png`（2032×7104，pad=24/lab=44/cw=980/ch=1348）：

- row5 我方頁：白色內容止於 x=1980，x=1981 起為 **(18,18,24)** 畫布色帶寬 **28px** 貼到格子右緣。
- row5 LO 頁：白色內容止於 x=976，x=977 起同款 (18,18,24) **28px** 帶——**LO 側其實一樣有**，
  「LO 無」是錯覺（LO 頁較窄帶子更貼格子縫隙，視觉上被當成分隔條）。
- row4（schemecolor）兩側同款 28px；row1（fdo68607，612×792 US Letter）頁寬恰好=cw=980，兩側黑帶=0，
  「有時有有時無」完全由**頁寬是否等於全表最大頁寬**決定。

根因：`make_cmp.py` 以全表最大頁（fdo68607：980px）定 `cw`，A4 檔（Bug51170、WC048、
schemecolor：595pt→953px）渲染圖只有 953px，`canvas.paste()` 左上對齊 → 右緣剩
980−953＝27px 畫布深色 (18,18,24) 與白頁直接相貼、無縫隙分隔，看上去像渲染出來的黑邊。
高度同理（1268 vs 1348）但底部不顯眼。

黑帶值 (18,18,24) 正是 `Image.new("RGB", ..., (18, 18, 24))` 的畫布底色，逐像素吻合，實錘。

### 2.3 關於「左緣」舊記載

row1 我方頁（980px 滿寬）無右帶；zoom 圖 `zoom_r1_header_quire.jpg` 的黑帶實為**該 crop 左半
LO 頁與格子邊界的縫隙色**，非 Quire 側缺陷。14:53「左緣」與本次「右緣」都是同一合成器
幾何在不同 crop 下的兩种錯覺，引擎側兩側皆無黑帶。
