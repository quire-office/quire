Quire 文書編輯器外殼原型（U1 窗體骨架）

歡迎使用 Quire 文書編輯器外殼原型。本視窗依據傳統桌上型文書處理器的 Ribbon 佈局慣例構建，整合了完整八大標籤（常用、插入、設計、版面配置、參考資料、校閱、檢視、說明）、快速存取工具列（QAT）、標尺系統與狀態列。

產品誠實紅線規範： 本外殼忠實反映 Quire 核心引擎能力。凡屬當前外殼與檢視既有能力者（如標籤切換、縮放滑桿 60%–180%、適合頁寬、閱讀/列印/Web 檢視模式、標尺切換與拖曳計算、8×5 表格選擇器與特殊符號面板），皆已實裝互動；其餘需要後續編輯、插入、樣式排版或校對引擎 API 支援的按鈕，皆嚴格標記為 pending:<依賴卡>，以置灰停用態呈現，游標帶有 not-allowed 並附 Tooltip 詳細提示，絕不粉飾或隱藏未完成功能。

Quire 編輯器外殼 - 系統說明

Quire 文書編輯器外殼 (U1 窗體骨架)

本外殼原型完全採用標準 HTML5、CSS 與純 JavaScript 實現，零新依賴、零第三方字型或圖示庫。

  • 快速存取工具列 (QAT)：提供檔案儲存、復原、重複與快速拼寫。
  • Ribbon 標籤列：支援滑鼠點擊切換與鍵盤方向鍵 (左右/Home/End) 無障礙導航。
  • 水平標尺與縮排：上方刻度依紙張寬度即時計算，三個滑桿可直接拖曳調整首行縮排、懸掛縮排與邊界。
  • 縮放與檢視模式：支援 60%–180% 等比縮放、頁寬適配與閱讀/列印/Web 檢視切換。
  • 命令事件匯流排：所有按鈕點擊皆派發至 window.QWordShell.onCommand(cmdId) 並記錄於 window.__qwordLog。
  • 誠實態設計：尚未接上引擎 API 的功能按鈕皆標示為 pending:<依賴卡> 並以停用態提示。
